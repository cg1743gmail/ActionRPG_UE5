## 3. 核心系统详解

### 3.1 GameplayAbility 系统 (GAS)

项目基于 UE5 的 **GameplayAbilitySystem** 构建，这是 ARPG 游戏的核心。

#### 核心类关系

```
ARPGCharacterBase
    ├── IAbilitySystemInterface (接口)
    ├── URPGAbilitySystemComponent*  ← ASC 实例
    └── URPGAttributeSet*            ← AttributeSet 实例
            │
            ├── Health / MaxHealth
            ├── Mana / MaxMana
            ├── AttackPower / DefensePower
            ├── MoveSpeed
            └── Damage (临时属性)
```

#### URPGAbilitySystemComponent (ASC)

```cpp
// 继承 UAbilitySystemComponent，扩展游戏特定功能
class URPGAbilitySystemComponent : public UAbilitySystemComponent
{
    // 按Tag获取激活中的Ability
    void GetActiveAbilitiesWithTags(const FGameplayTagContainer& Tags, ...);
    
    // 从Character获取默认Ability等级
    int32 GetDefaultAbilityLevel() const;
    
    // 静态工具函数：从Actor提取ASC
    static URPGAbilitySystemComponent* GetAbilitySystemComponentFromActor(...);
};
```

#### URPGAttributeSet (属性集)

| 属性 | 类型 | 说明 | 网络复制 |
|------|------|------|----------|
| `Health` | `FGameplayAttributeData` | 当前生命值 | `OnRep_Health` |
| `MaxHealth` | `FGameplayAttributeData` | 最大生命值 | `OnRep_MaxHealth` |
| `Mana` | `FGameplayAttributeData` | 当前魔法值 | `OnRep_Mana` |
| `MaxMana` | `FGameplayAttributeData` | 最大魔法值 | `OnRep_MaxMana` |
| `AttackPower` | `FGameplayAttributeData` | 攻击力倍率 | `OnRep_AttackPower` |
| `DefensePower` | `FGameplayAttributeData` | 防御力倍率 | `OnRep_DefensePower` |
| `MoveSpeed` | `FGameplayAttributeData` | 移动速度 | `OnRep_MoveSpeed` |
| `Damage` | `FGameplayAttributeData` | 临时伤害属性 | 无 (瞬态) |

**关键机制**:
- `PreAttributeChange()`: MaxHealth/MaxMana 变化时，按比例调整当前值
- `PostGameplayEffectExecute()`: Damage 属性应用后，扣除 Health 并触发事件


### 3.2 物品系统

物品系统采用 **PrimaryDataAsset** 架构，支持异步加载和资产管理。

#### URPGItem (物品基类)

```cpp
UCLASS(Abstract, BlueprintType)  // Abstract: 不可直接蓝图化
class URPGItem : public UPrimaryDataAsset
{
    // 类型标识 (由子类构造函数设置)
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly)
    FPrimaryAssetType ItemType;

    // 基础属性
    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    FText ItemName, ItemDescription;
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    FSlateBrush ItemIcon;
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    int32 Price, MaxCount, MaxLevel;

    // 关键: 物品可授予Ability
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = Abilities)
    TSubclassOf<URPGGameplayAbility> GrantedAbility;
    
    int32 AbilityLevel;  // Ability等级，<=0时使用CharacterLevel
};
```

### 3.3 游戏框架类

#### ARPGCharacterBase (角色基类)

```cpp
class ARPGCharacterBase : public ACharacter
                       , public IAbilitySystemInterface      // GAS接口
                       , public IGenericTeamAgentInterface   // AI团队识别
{
    // ASC & AttributeSet (关键组件)
    URPGAbilitySystemComponent* AbilitySystemComponent;
    URPGAttributeSet* AttributeSet;
    
    // 角色等级
    UPROPERTY(Replicated)
    int32 CharacterLevel;
    
    // 初始Ability列表
    TArray<TSubclassOf<URPGGameplayAbility>> GameplayAbilities;
    
    // 默认槽位Ability
    TMap<FRPGItemSlot, TSubclassOf<URPGGameplayAbility>> DefaultSlottedAbilities;
    
    // 被动GameplayEffect
    TArray<TSubclassOf<UGameplayEffect>> PassiveGameplayEffects;
    
    // 槽位 → AbilitySpecHandle 映射
    TMap<FRPGItemSlot, FGameplayAbilitySpecHandle> SlottedAbilities;

    // 核心生命周期
    virtual void PossessedBy(AController* NewController) override;  // 服务器初始化ASC
    virtual void OnRep_Controller() override;  // 客户端初始化ASC
    
    // Ability激活API
    bool ActivateAbilitiesWithItemSlot(FRPGItemSlot Slot, bool bAllowRemoteActivation = true);
    bool ActivateAbilitiesWithTags(FGameplayTagContainer Tags, bool bAllowRemoteActivation = true);
    bool GetCooldownRemainingForTag(FGameplayTagContainer CooldownTags, ...);

    // Blueprint事件 (由AttributeSet触发)
    UFUNCTION(BlueprintImplementableEvent)
    void OnDamaged(float Damage, const FHitResult& Hit, ...);
    
    UFUNCTION(BlueprintImplementableEvent)
    void OnHealthChanged(float Delta, const FGameplayTagContainer& Tags);
    
    // AttributeSet访问友元
    friend URPGAttributeSet;  // 允许AttributeSet调用HandleDamage等
};
```

**GAS 初始化流程**:

```
服务器: PossessedBy() → InitAbilityActorInfo()
                    → AddStartupGameplayAbilities()
                    → AddSlottedGameplayAbilities()

客户端: OnRep_Controller() → InitAbilityActorInfo()
                          → 绑定InventoryDelegate
```


## 5. 关键技术点

### 5.1 网络复制策略

| 组件 | 复制方式 | 说明 |
|------|----------|------|
| `URPGAttributeSet` | `OnRep_*` + `DOREPLIFETIME` | 属性自动复制，支持预测 |
| `ARPGCharacterBase::CharacterLevel` | `UPROPERTY(Replicated)` | 等级同步 |
| `URPGGameplayAbility` | 由ASC管理 | Spec自动复制 |
| `URPGSaveGame` | 服务器写入 | 客户端不直接保存 |

### 5.2 GameplayTag 使用场景

```
Ability.Tag          → 技能分类、激活条件
Effect.Tag           → 效果类型、免疫判断
Cooldown.Tag         → 冷却组管理
Event.Tag            → Ability触发事件
Container.Tag        → EffectContainer映射键
```

### 5.3 GameplayEffectContainer 模式

**优势**:
- 蓝图可配置 (EditDefaultsOnly)
- Tag驱动效果选择
- 支持多目标类型
- 运行时Spec封装

**典型用法**:
```cpp
// 蓝图配置: EffectContainerMap["Damage"] = { TargetType, [GE_Damage, GE_Stun] }

// C++ 调用
ApplyEffectContainer(FGameplayTag("Ability.Damage"), EventData);
```

### 5.4 物品-技能绑定机制

```
URPGItem.GrantedAbility  ──┐
                           │  装备时
                           ▼
ARPGCharacterBase.SlottedAbilities[Slot] = SpecHandle
                           │
                           │  激活时
                           ▼
ActivateAbilitiesWithItemSlot(Slot)
```

### 5.5 存档版本迁移

```cpp
// ERPGSaveGameVersion 枚举
enum type {
    Initial,        // 初始版本
    AddedInventory, // +背包数据
    AddedItemData,  // +物品数量/等级
    // 新版本在此添加
};

// Serialize() 中处理迁移
virtual void Serialize(FArchive& Ar) override;
```

### 5.6 属性变化响应链

```
GameplayEffect 应用
       │
       ▼
URPGAttributeSet::PostGameplayEffectExecute()
       │
       ├── Data.EvaluatedData.Attribute == Damage
       │       └── Health -= Damage
       │       └── Character->HandleDamage()
       │
       ├── Data.EvaluatedData.Attribute == Health
       │       └── Clamp(0, MaxHealth)
       │       └── Character->HandleHealthChanged()
       │
       └── Data.EvaluatedData.Attribute == Mana
               └── Clamp(0, MaxMana)
               └── Character->HandleManaChanged()
```

## 8. 架构优缺点评估

### 优点

| 方面 | 说明 |
|------|------|
| **GAS标准化** | 技能系统完全基于GAS，符合UE5最佳实践 |
| **数据驱动** | 物品/技能通过PrimaryDataAsset配置，蓝图友好 |
| **网络就绪** | 属性复制、AbilitySpec复制已内置支持 |
| **解耦设计** | InventoryInterface解耦背包与角色 |
| **版本迁移** | SaveGame支持版本升级，数据不丢失 |
| **事件驱动** | 属性变化通过Delegate通知，易于扩展 |

### 局限

| 方面 | 说明 |
|------|------|
| **无网络验证** | 缺少Ability激活的服务器校验逻辑 |
| **无预测机制** | 客户端无预测，纯权威模式 |
| **无技能CD UI** | 未提供冷却时间UI组件 |
| **无Buff系统** | 缺少可视化的Buff/Debuff管理 |
| **无技能树** | 未实现技能解锁/升级树 |

## 9. 总结

ActionRPG 是 **Epic 官方 ARPG 模板**，架构设计精良，核心围绕：

```
┌─────────────────────────────────────────────────┐
│  GameplayAbilitySystem (GAS)                    │
│       ↓                                         │
│  URPGAttributeSet (属性)                        │
│       ↓                                         │
│  URPGGameplayAbility (技能)                     │
│       ↓                                         │
│  URPGItem + PrimaryDataAsset (物品数据)         │
│       ↓                                         │
│  IRPGInventoryInterface (背包接口)              │
│       ↓                                         │
│  URPGSaveGame (存档持久化)                       │
└─────────────────────────────────────────────────┘
```

**适用场景**:
- ARPG / Action RPG
- MMORPG (需扩展网络层)
- 卡牌/战棋游戏 (复用GAS)
- 技能驱动的任何游戏类型

**学习价值**:
- GAS完整实现范例
- PrimaryDataAsset最佳实践
- 存档版本迁移模式
- 接口解耦设计模式
